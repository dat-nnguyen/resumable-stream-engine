# Repository Agent Guidelines

This repository implements a high-performance, memory-bounded resumable file streaming engine with backpressure control using Node.js and PostgreSQL.

## Agent skills

### Issue tracker

Issues and specs for this repository live as GitHub issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Canonical triage roles map directly to GitHub issue labels. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context repository layout (`CONTEXT.md` + `docs/adr/`). See `docs/agents/domain.md`.
